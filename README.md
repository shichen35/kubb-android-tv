# 酷播 · Android TV

一个给 Android TV / Google TV 用的酷播（[kubb.tv](https://www.kubb.tv)）客户端：只用遥控器方向键，就能找片、看剧、接着上次的进度往下看。

用 Kotlin、Jetpack Compose for TV 和 Media3 ExoPlayer 实现，界面和播放器的写法参考了 [olevod-tv-app](https://github.com/abdvl/olevod-tv-app)。

这是个人项目，仅供学习交流，与酷播官方没有任何关系。影片、海报和播放源都来自 kubb.tv 的公开接口，相关权利归原权利人所有。

| | |
| --- | --- |
| 设备 | Android TV / Google TV，Android 8.0（API 26）及以上 |
| 操作 | 遥控器方向键、确认键、返回键；支持系统输入法 |
| 包名 | `com.kubb.tv` |
| 安装 | 侧载 APK，不在应用商店上架 |

## 安装

从 [Releases](https://github.com/shichen35/kubb-android-tv/releases/latest) 下载最新的 APK，侧载到电视上（例如 `adb install kubb-tv-1.0.0.apk`）。首次安装需要在电视设置里允许安装未知来源的应用。

## 功能

- **首页**：精选推荐、继续观看（带进度条）、我的收藏、热播榜（四个频道周榜交替），以及电影、电视剧、综艺、动漫、短剧的热门排行。
- **频道**：电影、电视剧、综艺、动漫、短剧、体育、纪录片。按类型和排序（最近更新、最新上线、最热、评分）筛选，「额外筛选」里再按地区、语言、年份、连载状态和横竖屏过滤；列表往下滚自动加载。站点每个条件最多给 30 页。
- **搜索**：系统输入法输入片名，侧栏有热门搜索和最近搜索。
- **详情**：简介、导演主演、评分、地区、热度；主按钮会根据观看记录显示「播放第 1 集」「继续观看第 N 集」或「重新观看」；超过 60 集按 50 集一组分段。
- **播放**：从上次的位置继续；左右键快退快进 15 秒；剧集最后 30 秒提示「即将播放」，按确认立即播放，结束后自动接下一集；下键呼出控制栏，再按下键打开选集条。播放地址过期（403）时自动换新地址接着播。
- **收藏与历史**：只保存在本机。历史最多 40 部，「管理」里可逐条删除或清空。

## 遥控器操作

| 位置 | 按键 | 作用 |
| --- | --- | --- |
| 顶部标签栏 | 左右 | 切换标签，页面随之切换 |
| 内容区 | 返回 | 回到顶部标签栏 |
| 顶部标签栏 | 返回 | 回到首页；在首页时退出应用 |
| 详情页、播放页 | 返回 | 回到上一页，焦点回到原来的位置 |
| 播放中 | 确认 | 暂停或继续；「即将播放」出现时立即播放下一集 |
| 播放中 | 左 / 右 | 后退或前进 15 秒 |
| 播放中 | 下 | 呼出控制栏；再按一次打开选集条 |
| 播放中 | 上 | 收起控制栏或「即将播放」提示 |
| 播放中 | 媒体键 | 播放、暂停、停止；快进快退每次 30 秒 |

## 已知限制

- 不登录，只能播放免费的 576P（标清）；更高清晰度和会员剧集播不了。
- 没有清晰度和线路切换、倍速、字幕样式和跳过片头片尾。
- 站点没有拼音首字母搜索和联想接口，只能输入完整片名的一部分。
- 收藏和观看历史只保存在本机，卸载应用会一并清除。
- 站点要求人机验证时，电视上过不了，只能稍后再试。
- 已在平板模拟器上用方向键和真实数据走通首页、频道、搜索、详情、播放和续播，还没有在 Android TV 真机上跑过。

## 开发

需要 JDK 17 或更新版本和 Android SDK（compileSdk 37）。

```bash
./tools/check.sh                 # lint（警告即失败）、单元测试、构建 debug APK
./gradlew :app:installDebug      # 安装到已连接的电视或模拟器
```

发版：在 `app/build.gradle.kts` 里改版本号，把发布说明写进 `docs/releases/vX.Y.Z.md`，提交后推送同名 tag（如 `git tag v1.0.0 && git push origin v1.0.0`）。GitHub Actions 会跑完检查、用仓库 Secrets 里的密钥签名，并发布 Release。

代码结构：

| 位置 | 内容 |
| --- | --- |
| `app/src/main/java/com/kubb/tv/data/` | 站点域名与请求信封、重试（`Gateway`，换域名只改 `DOMAIN` 一处）、签名（`Signature`）、业务接口与归一化（`CatalogApi`）、频道与筛选项（`Taxonomy`）、续播规则（`WatchState`）、本机收藏与历史（`Library`） |
| `app/src/main/java/com/kubb/tv/` | 应用外壳与导航（`TvApp`）、各页面、播放器（`PlayerScreen`）、分页加载（`PagedFeed`） |
| `app/src/test/` | 单元测试：浏览器抓到的签名向量、真实响应裁剪的接口夹具、续播规则、本机存储、分页 |
