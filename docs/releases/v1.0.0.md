酷播 TV 的第一个正式版本，适用于 Android TV / Google TV（Android 8.0 及以上）。

## 下载与安装

下载下方的 `kubb-tv-1.0.0.apk`，用 U 盘、局域网传输工具或 `adb install kubb-tv-1.0.0.apk` 侧载到电视上。首次安装需要在电视设置里允许安装未知来源的应用。

## 功能

- 首页：精选推荐、继续观看、我的收藏、热播榜，以及电影、电视剧、综艺、动漫、短剧的热门排行。
- 频道：电影、电视剧、综艺、动漫、短剧、体育、纪录片，按类型、排序和地区、语言、年份等条件筛选，往下滚自动加载。
- 搜索：系统输入法输入片名，附热门搜索和最近搜索。
- 详情：简介、主创、评分；按观看记录显示「播放」「继续观看第 N 集」或「重新观看」；长剧按 50 集分组。
- 播放：从上次的位置继续；左右键快退快进 15 秒；剧集结尾提示并自动播放下一集；下键打开选集条；播放地址过期时自动换新地址续播。
- 收藏和观看历史保存在本机。

## 已知限制

- 不登录，只能播放免费的 576P（标清）；更高清晰度和会员剧集播不了。
- 没有清晰度切换、倍速和字幕设置。
- 已在平板模拟器上用真实数据验证，还没有在 Android TV 真机上测试过。
